Privacy Policy - Vectr

Last updated: July 24, 2026
This page is the public policy for Vectr on Google Play.

1. Who we are

Vectr is a local mobile IDE with an optional AI agent, developed by DMTech Softworks. The app runs on your device.

2. Data we process

  • API keys and preferences are stored on your device (encrypted prefs where applicable).
  • Project files you open via the system file picker stay under your control (SAF). Vectr does not upload your project to our servers.
  • Chat history is stored locally in an on-device database.
  • When you use the agent, prompts and tool results are sent to the AI provider YOU configure (e.g. DeepSeek or an OpenAI-compatible endpoint). We do not operate that API.

3. Optional network features

  • Web search / fetch_url may contact third-party sites (e.g. DuckDuckGo) to answer questions.
  • Notifications (Android 13+) show when the agent works in the background or needs approval - only if you allow them.

4. Commands, file edits, and approvals

  • By default, shell commands and file edits from the agent require your confirmation in the app (pending bar and/or approval notifications).
  • Optionally, in Settings → Trust & approvals, you can whitelist program names so matching commands auto-run; enable auto-accept for file edits; choose the auto-run runner (built-in Shell or Termux).
  • These options are off by default and under your control.

5. Optional Termux integration

  • Vectr can ask Termux to run shell commands (after your confirmation, or auto-run if you whitelisted the program and chose Termux as runner).
  • This requires Termux and Termux:Tasker installed from F-Droid, plus the special permission “Run commands in Termux environment”.
  • Termux is optional. You can skip it and still use files, editor, and the agent (without Termux shell tools).

6. Permissions summary

  • Internet - AI provider API and optional web search/fetch.
  • Notifications - progress of background AI work and approval prompts.
  • Foreground service (dataSync) - keep the AI stream alive when the app is in the background.
  • Termux RUN_COMMAND - only to run shell commands via Termux when you use that integration.
  • Storage access - only folders/files you explicitly open.

7. Children

Vectr is not directed at children under 13.

9. Changes

We may update this policy in app updates. Continued use after an update means you accept the revised text shown at first launch / in Settings. This web page reflects the same policy for Google Play.

1. Кто мы

Vectr - локальная мобильная IDE с опциональным ИИ-агентом от DMTech Softworks. Приложение работает на твоём устройстве.

2. Какие данные обрабатываются

  • API-ключи и настройки хранятся на устройстве (где возможно - в зашифрованных prefs).
  • Файлы проекта, которые ты открываешь через системный выбор папки (SAF), остаются под твоим контролем. Vectr не загружает проект на наши серверы.
  • История чатов хранится локально в базе на устройстве.
  • Когда ты пользуешься агентом, промпты и результаты инструментов уходят к API-провайдеру, который ТЫ указал (DeepSeek или OpenAI-compatible). Мы этот API не предоставляем.

3. Опциональная сеть

  • web_search / fetch_url могут обращаться к сторонним сайтам (например DuckDuckGo).
  • Уведомления (Android 13+) показывают работу агента в фоне или запросы на подтверждение - только если ты разрешишь.

4. Команды, правки файлов и подтверждения

  • По умолчанию shell-команды и правки файлов от агента требуют твоего подтверждения в приложении (полоса pending и/или уведомления).
  • Опционально в Настройки → Доверие и подтверждения можно добавить программы в whitelist, включить авто-принятие правок файлов и выбрать runner (встроенный Shell или Termux).
  • Эти опции по умолчанию выключены и управляются тобой.

5. Опциональный Termux

  • Vectr может попросить Termux выполнить shell-команду (после твоего подтверждения или автоматически, если программа в whitelist и выбран runner Termux).
  • Нужны Termux и Termux:Tasker из F-Droid и особое разрешение «Выполнение команд в среде Termux».
  • Termux необязателен: можно пользоваться файлами, редактором и агентом без shell через Termux.

6. Разрешения

  • Интернет - API провайдера ИИ и опциональный web search/fetch.
  • Уведомления - прогресс фоновой работы ИИ и запросы на подтверждение.
  • Foreground service (dataSync) - чтобы AI-стрим не убивался при сворачивании приложения.
  • Termux RUN_COMMAND - только для shell через Termux, если ты этим пользуешься.
  • Доступ к файлам - только к папкам/файлам, которые ты сам открыл.
